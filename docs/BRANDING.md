# Evendly branding

- Product: **Evendly**
- Tagline: **Discover events. Save moments.**

The application display names, web metadata, and Flutter title use Evendly. `assets/images/logo.png` and `assets/images/logo_splash.png` were retained because they are existing raster assets. If either contains baked-in GoEvent artwork, replace it manually with approved Evendly artwork at the same path and regenerate the native splash screen with `dart run flutter_native_splash:create`.

Firebase-bound native identifiers deliberately remain unchanged. See the README for details.
